# SniffHub — Social & Dating App with Event-Centered Discovery

## Overview
SniffHub is a production-ready native Android social discovery and dating application that combines the familiar swipe-based matching experience of platforms like Tinder and Bumble with a unique event-first social networking system.
Unlike traditional dating apps that focus only on profile browsing, SniffHub introduces Hub Mode, where users connect through real-life experiences such as festivals, venues, trips, and social gatherings. This approach creates more meaningful interactions by allowing users to discover people not only by appearance, but through shared communities and activities.
Published on Google Play with 10k+ downloads, SniffHub is built as a scalable mobile product integrating modern Android development practices, real-time communication, cloud infrastructure, and monetization systems.


SniffHub is a production-ready Android application that combines **swipe-based dating** with a second social mode called **Hub Mode**, where users connect through **real-world events** such as festivals, clubs, and venues.

The app provides a full modern matchmaking experience including onboarding, real-time chat, media sharing, event feeds, premium subscriptions, and audio/video calling.


## ✨ Main Features
### 🔐 Authentication & Onboarding
- Firebase Authentication (Google + Email login)
- Deep onboarding flow (13-step profile builder)
- Profile fields include:
  - Gender & preferences
  - Birthdate & age calculation
  - Languages, interests, zodiac sign, job, hometown
- Media upload support (1–6 images/videos)
- Image editing: crop, rotate, filters

### 💘 Dating Mode (Swipe Discovery)
- Swipe cards (Like / Dislike / Super Like)
- Rewind last swipe
- Boost system (time-based visibility increase)
- Advanced filters:
  - Age & distance range
  - Interests, gender, hometown, looking-for options
- Premium gating:
  - Likes screen blurred for free users
  - Full access for premium subscribers
 
### 💬 Real-Time Messaging & Chat
- Match-based chat system
- WhatsApp-style conversation list
- Rich messaging:
  - Text, images, videos
  - Voice messages
  - GIFs + emoji support
- Message reactions
- Built-in message translation
- Report/block/delete match options

### 📞 Audio & Video Calling
- Twilio Video (WebRTC-based)
- Call invitations via Firebase Cloud Messaging (FCM)
- Dedicated call UI (accept/decline flow)

### 🎉 Hub Mode — Event-Centered Social Discovery
- Discover nearby festivals, venues, and events
- Attend/leave events
- Event feeds (Twitter-style posting system)
- Comments, likes, reporting
- Stage + timetable scheduling for large events
- Hub-style profiles with event posts + direct chat entry


### 👤 Profile & Settings
- Profile completion indicator
- Full profile editor (media + personal info)
- Verification system (camera pose check)
- Settings include:
  - Notification controls
  - Incognito mode, freeze account, hide profile
  - Mode switching (Dating ↔ Hub)
  - Delete/logout support



### 💳 Monetization (Google Play Billing)
- Subscription tiers:
  - Starter / Pro / Ultimate
- Consumable packs:
  - Boosts
  - Super Likes
  - Direct Messages
- Premium feature access control + credit system
